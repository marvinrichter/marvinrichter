## JVM Architecture

**[spring-hexagonal-archetype](https://github.com/marvinrichter/spring-hexagonal-archetype)**: Maven archetype that generates a Spring Boot 4 project on Java 25 with hexagonal (ports-and-adapters) architecture. ArchUnit checks the boundaries on every build and fails it on a violation. Ships one working vertical slice, Testcontainers integration tests and Micrometer.
`Java 25` `Spring Boot 4` `Hexagonal Architecture` `ArchUnit` `Testcontainers`

**[jvm-modernisation-playbook](https://github.com/marvinrichter/jvm-modernisation-playbook)**: Strangler Fig, Branch-by-Abstraction and Anti-Corruption Layer for moving a legacy JVM monolith to Spring Boot. Each pattern is a runnable before/after project with a feature flag that switches between the legacy and the hexagonal target. [Read the playbook](https://marvinrichter.github.io/jvm-modernisation-playbook)
`Java 21` `Spring Boot` `Strangler Fig` `Branch-by-Abstraction` `ACL`
